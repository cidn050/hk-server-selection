## 几个容易踩坑的地方

**IP 更换政策**：1核1G 和 1核2G 的套餐，更换 IP 要额外收费（除非 IP 本身有问题）。其他配置可以免费换一次 IP，第二次开始收费。如果你对 IP 有特殊要求，比如要做邮件服务器或者需要干净 IP，最好一开始就测试好。

**带宽类型别选错**：CN2 GIA 是电信高级网络，速度最快、最稳定，但带宽上限通常较小（2M-10M）。BGP 优化线路带宽大（50M-100M），但国内访问速度稍弱。看你业务面向国内还是海外，别只盯着带宽数字选。

**Windows 系统要选对配置**：Windows Server 比 Linux 吃资源，1核1G 跑 Windows 会很吃力，至少要 2核4G 起步。如果你只是跑个博客或者 PHP 应用，Linux 完全够用，没必要为了 Windows 多花钱。

**高防不是免费送的**：普通云服务器和物理服务器默认不带 DDoS 防护，攻击超出阈值会被自动封停 IP。需要防护要单独购买高防服务器或者额外加购 DDoS 防护服务。
